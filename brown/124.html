No. 124: Bow drill

A bow is pushed to and fro along its string. The string is wound once round a small wheel on a drill, so the drill spins one way, then the other. One hand's straight to-and-fro push becomes a quick turning.

How it works

Push the bow along its string and the string slides past the spool. The string cannot slip, so it drags the spool round with it. Pull the bow back and the spool turns back too.

The string is wound once round the spool, so one side of it leaves in front and the other behind. The bow moves the same distance the string moves. The red beads on the string show this. At the end of each stroke the bow stops for a moment, and so does the spindle.

The drill bit turns with the spindle and cuts where it touches. Try the wide spool, then the narrow one, and compare how far the spindle turns on each stroke.

In Brown's words

Fiddle drill. Reciprocating rectilinear motion of the bow, the string of which passes around the pulley on the spindle carrying the drill, producing alternating rotary motion of the drill.

This model is rebuilt from Brown's drawing. The drawing shows the spool end on, so the spindle, the bit, the block, the post and the arm that holds the top of the spindle were made up. The string is shown wound once round with a small gap between the two sides. The sizes are made up. The narrow spool is added to show the effect of size.
